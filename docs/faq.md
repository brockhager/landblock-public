# Landblock FAQ

## What is this repository for?

This repository publishes public information about Landblock, including its
vision, principles, roadmap, and other high-level documentation.

## Is this the full project?

No. The implementation is developed privately. This repository is a public
documentation surface, not the operational project itself.

## Why is the source code not included?

The project is intentionally separating public explanation from private
implementation. This repository is meant to communicate direction and framing
without exposing code or other sensitive project material.

## Can I contribute code?

No. Public code contributions are not being accepted in this repository.

## What kind of information will be published here?

Only information that is suitable for a public audience, such as conceptual
descriptions, project framing, non-operational architecture, roadmap context,
and other materials that do not expose the private implementation.

## What will not be published here?

This repository should not contain source code, algorithms, schemas,
infrastructure details, security-sensitive information, operational procedures,
or anything that would materially enable reimplementation.

## Is the whitepaper a specification?

No. The whitepaper is a public conceptual document. It should not be read as a
protocol specification, API contract, or implementation guide.

## Does the roadmap represent commitments?

No. The roadmap communicates intent and current direction. It may change as the
project evolves.
