# Common Questions

## Is Landblock only a blockchain project?

No. It includes front-end applications, service orchestration, identity and evidence workflows, and operational infrastructure in addition to protocol components.

## Does Landblock replace legal institutions?

No. Landblock improves technical trust, traceability, and process support. Legal frameworks and institutions remain essential.

## Why are there multiple apps?

Different user groups need different workflows. Separate applications improve clarity, usability, and security boundaries.

## Why split the protocol into modules?

Module boundaries make the system easier to reason about, test, evolve, and govern.

## Is the architecture final?

No. Landblock Core is under active development. Names, internals, and integrations can change as the project matures.
