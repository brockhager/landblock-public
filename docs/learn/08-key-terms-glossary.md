# Key Terms Glossary

This glossary explains common words used across Landblock documents in simple language.

## API

A way for software systems to talk to each other using defined requests and responses.

## Audit trail

A history of what changed, who changed it, and when it changed.

## Authorization

Rules that decide what an authenticated user is allowed to do.

## Authentication

The process of confirming who a user or system is.

## DID (Decentralized Identifier)

A digital identity format designed to support verifiable identity without relying on a single centralized provider.

## Evidence artifact

A supporting file or record (document, image, metadata) attached to a claim or workflow.

## Parcel registry

The set of records that track parcel details, state, and lifecycle events.

## Property token

A digital representation of ownership-related state in the protocol model.

## Dispute record

A formal record used when ownership or claim details are contested.

## Gas station

A component that helps handle transaction fees in supported workflows.

## Validator

A trusted participant or process that checks whether actions meet policy and technical rules.

## Governance

The framework of rules and decision processes that define how system actions are approved, reviewed, and changed over time.

## Why this page helps

Beginners can use this glossary as a quick reference while reading the rest of the learning path.
